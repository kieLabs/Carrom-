# CARROM POOL – GAMERKIE EDITION

Self-contained HTML5 Canvas + CSS + Vanilla JavaScript browser game. It uses no external images, audio URLs, libraries, CDNs, or APIs.

## Run
Open `index.html` in a modern browser. For mobile use, publish it with GitHub Pages and open the HTTPS URL.

## GitHub Pages
1. Create a repository named `Carrom-Pool-GamerKie`.
2. Upload `index.html` to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch → `main` → `/(root)` → Save.
5. After deployment, open `https://YOUR-USERNAME.github.io/Carrom-Pool-GamerKie/`.

## Controls
- Move the striker using the slider below the board.
- Touch/click the striker, drag backwards to aim, then release to shoot.
- Sound is synthesized through Web Audio API after user interaction.
- Pause, Rules, AI difficulty and Home controls are available.

## Important scope note
This is an original offline browser implementation, not an official Carrom Pool clone. It contains a custom lightweight physics and rules implementation and needs real-device playtesting before public launch. Online multiplayer, matchmaking, server accounts, purchases and tournament services are not included.
