# GitHub Upload Guide (Hindi)

1. ZIP download karke extract karein.
2. GitHub par `Carrom-Pool-GamerKie` naam ka repository banayein.
3. Extracted folder ke andar ka `index.html` repository ke root mein upload karein.
4. Repository → Settings → Pages kholein.
5. `Deploy from a branch`, branch `main`, folder `/(root)` select karke Save karein.
6. Deployment complete hone ke baad GitHub Pages URL open karein.
